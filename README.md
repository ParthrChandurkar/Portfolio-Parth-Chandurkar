## Run Locally

Prerequisites:

- Node.js 20.19+ or 22.12+
- npm 10+

Setup:

```bash
git clone https://github.com/ParthrChandurkar/Portfolio-Parth-Chandurkar.git
cd Portfolio-Parth-Chandurkar
npm install
npm run dev
```

Open the local URL printed by Vite, usually:

```text
http://127.0.0.1:5173
```

Production build:

```bash
npm run build
npm run preview
```

## Content Maintenance

Most public portfolio content lives in [src/App.jsx](src/App.jsx):

- `profile`
- `stackGroups`
- `projects`
- `research`
- `certifications`
- `learningPath`

Global layout, responsive behavior, and animation styling live in [src/styles.css](src/styles.css). Static assets live in [public/](public/).

Before publishing updates:

```bash
npm run build
```

Also verify:

- Resume opens from `/Parth_Rajesh_Chandurkar_Resume.pdf`
- GitHub, LinkedIn, IEEE, and project links are current
- Desktop and mobile layouts do not overflow
- Navigation scrolls to each section
- No unsupported claims or fabricated statistics are added
